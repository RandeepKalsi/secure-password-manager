# Secure Password Manager

A C# console-based password manager developed as a university software development project.

## Features

- Create and store password records
- Retrieve stored passwords
- Generate random 12-character passwords
- Validate minimum password length
- Store records using local file I/O
- Search stored records by website
- Case-insensitive search
- Basic encryption/decryption to demonstrate security concepts
- Menu-driven console interface
- Object-oriented design using a `PasswordManager` class

## Technologies

- C#
- Object-Oriented Programming
- File I/O
- Console Application
- Encryption Concepts

## What I Learned

This project provided practical experience with:

- C# programming
- Classes and object-oriented design
- File handling and persistent data storage
- Input validation
- Random password generation
- Searching and manipulating stored records
- Implementing basic encryption/decryption concepts
- Designing a menu-driven console application

## Security Note

This project is an educational demonstration of password-management and encryption concepts. The encryption implementation is intentionally basic and should not be used for protecting real passwords or sensitive information.

## How to Run

1. Clone the repository.
2. Open the project in a C#/.NET development environment.
3. Build the project.
4. Run the console application.
5. Follow the menu options to create, retrieve and search password records.
